# AGRABO Asset Folder

Use this folder for website media.

```text
assets/
  logos/          AGRABO logo files
  products/       Deli Honey product photos
  team/           staff or founder photos
  testimonials/   customer photos
  icons/          custom icons if Bootstrap Icons is not enough
  backgrounds/    hero and section background images
```

Recommended file names:

```text
agrabo-logo.png
deli-honey-250g.jpg
deli-honey-500g.jpg
deli-honey-1kg.jpg
```

In Angular templates, reference files like this:

```html
<img src="assets/products/deli-honey-500g.jpg" alt="Deli Honey 500g">
```
